# Aesir Enterprises GitHub Defaults

Organization-wide GitHub templates and public contribution guidance for Aesir Enterprises.

## Purpose

This public repository provides default community-health files, pull-request templates, issue templates, security-reporting guidance, and organization profile content for repositories that do not define their own versions.

## Public-content rule

Everything in this repository is publicly visible. Do not include:

- Credentials, tokens, or private keys
- Internal architecture or security configuration
- Customer, employee, or vendor information
- Private business plans or financial information
- Internal incident details
- Confidential repository names or links

Internal policies and operating standards are maintained in private repositories.

## Override behavior

An individual repository may provide its own supported community-health file or template when its needs differ from these defaults.

## Maintenance

Changes should use a pull request and human review.
