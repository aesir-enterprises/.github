# Security Policy

## Reporting a vulnerability

Do not disclose vulnerabilities in a public issue, discussion, pull request, or comment.

Use GitHub private vulnerability reporting when it is enabled for the affected repository. Otherwise, contact an Aesir Enterprises organization owner through an established private business channel.

Include:

- Affected repository or system
- Description and potential impact
- Reproduction steps
- Relevant versions
- Suggested mitigation, if known

Do not include real credentials, customer data, payment data, or unnecessary personal information.

## Response

Aesir Enterprises will review the report, determine severity, coordinate remediation, and communicate next steps through a private channel.

## Scope

This policy provides reporting guidance. It does not authorize testing that disrupts services, accesses data without permission, degrades availability, or violates applicable law.
